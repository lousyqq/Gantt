我的身分

01系統在做什麼全體

一張橫跨整年的甘特圖，列出每位成員的專案與「計畫區間」（排定的起訖週）。每到一週，成員針對當週有排到的每個區間打卡回報；主管據此評分、回覆與講評；高階主管則透過成果清單檢視全年度的具體產出與 MP Saving。

三種角色、三種節奏

成員

每週回報三件事

當週排到的任務打卡、下週預計執行工作（必填）、非專案事項（選填）。全部集中在 header 的 📋 本週回報中心。

主管

排程、催報、評分、講評

建立專案與計畫區間；用 📊 團隊總結 看板逐人檢視本週回報，複製催報名單、給分數、留週報回覆。

高階主管

看產出

切到 成果清單，用 KPI 卡片篩出重點關注／有具體產出／有 MP Saving 的專案，需要時匯出 Excel。

關於「週次」

系統的週次跟公司行事曆一樣（等同 Excel 的 WEEKNUM）：一週從週日開始，含 1/1 的那一週是 W01，跨年照日期切——12/31 屬於舊年度的最後一週、1/1 起就是新年度的 W01。由今天的日期自動推算；2026、2027 年都是 53 週。

header 中央「系統週數」旁邊會顯示那一週的日期區間（例如「09/13–09/19」），甘特圖週次表頭滑過去也看得到。跨年的短週看日期就知道是哪幾天（2026 W53＝12/27–12/31；2027 W01 只有 01/01–01/02，都不是上班日，所以 1/4 上班時系統已是 W02）。年底最後一週的回報請在 12/31（四）前完成——1/1 起系統就進入新年度，W53 變成歷史週次；漏交的話請主管開放「歷史補登」再補。

「系統週數」顯示的是你目前正在檢視的那一週，不一定等於本週。尚未到的週次一律不能回報——成員切不到未來週；主管可以切過去看排程，但打卡、非專案、下週預計、主管回覆、評分都不開放（header 會出現「📅 未來週次・僅檢視」提示）。

02快速上手（依角色）全體

只想馬上開始用？找到你的角色那一張卡，照順序做一遍就會了。每一步都寫出畫面上要點的那個按鈕；細節與例外在後面各章。

👤 成員：5 分鐘上手

  1. 登入在登入畫面下半部點自己的名字（沒有密碼）。右上角會顯示你的名字與「成員」。
  2. 看懂自己的甘特圖登入後畫面只顯示你自己的專案（工具列的成員下拉預設是你）。黃色斜紋條＝主管幫你排的計畫區間；直立的紅線＝本週；條上出現紅框＋❗＝這條區間本週該打卡、還沒打。
  3. 打開回報中心按 header 的 📋 本週回報中心（紅色數字＝還沒完成的項目數）。面板由上到下三區：①本週待打卡任務 ②下週預計執行工作（必填）③非專案事項（選填）。
  4. 逐一打卡點任一筆待打卡任務 → 選狀態（有執行／Monitor／未執行 三選一）→ 寫工作說明（選「有執行」時必填）→ 可選貼一個文件連結 → 儲存進度回報。想照抄上週：狀態還沒選時按 ↩ 沿用上次回報 一鍵帶入。
  5. 填下週預計回到回報中心點「下週預計執行工作」→ 寫下一週打算做什麼 → 儲存。這一項每週必填，沒填會一直算在紅色數字裡。
  6. （選填）非專案事項臨時支援、會議、教育訓練等不屬於專案的工作寫在這裡，主管在看板看得到。
  7. 看到 🎉 就完成了三件事都齊全時回報中心底部會變成綠色的「🎉 本週回報已全數完成」。之後這週內隨時可以回來改（回報中心最下方「已完成打卡任務」→ 修改）。
  8. 看主管回饋按 📊 W○○ 團隊總結，自己那一列會顯示本週得分（🏆）；主管若有留話，卡片下方會有紫色的「👑 主管回覆」。

成員的一週長什麼樣

  • 週日新的一週開始，本週該打卡的條出現紅框
  • 週間做到哪就打卡到哪，可以反覆修改
  • 週末前三件事齊全，🎉 完成；主管開始評分
  • 下週上週變成唯讀；需要改要請主管開「歷史補登」

你自己就能維護的兩樣東西

  • 子區間：把主管排的計畫區間再切成幾個階段（例如 準備資料／跟 IT 溝通／驗證），在打卡視窗最下方的「排程與子區間」卡裡加。負責人自己就能增刪改，不必等主管。詳見子區間章。
  • 🎯 具體產出與 MP Saving：專案名稱列最右邊的 🎯 圖示，填這個專案做完會交付什麼、預計省多少人力。這是高階主管在成果清單看的內容，負責人請自己填。

要新增專案或計畫區間？找主管

成員不能自己建專案與計畫區間（那是主管排程的權責），也不能改起訖週。需要時請主管在甘特圖上加。

👑 主管：兩條流程

主管的工作分兩種：建置（年初或有新專案時，把排程放上去）與每週例行（催報、評分、講評、出週報）。

A. 建置流程（年初／新專案）

  • ⚙️ 管理 → 成員管理先把人加進來
  • ＋ 新增專案成員群組列右側的按鈕
  • ＋ 新增計畫區間滑到專案名稱列，右側綠色 ＋
  • （選）子區間點甘特條 → 排程與子區間
  • 🎯 產出可先填，或交給負責人填
  1. 登入登入畫面最上方的 👑 主管登入。登入後預設看到全部成員的專案，依成員分組。
  2. 新增成員右上角 ⚙️ 管理 ▾ → 👥 成員管理 → 輸入姓名新增。新成員會立刻出現在登入畫面與甘特圖上。
  3. 新增專案甘特圖左側每位成員的群組列右側有 ＋ 新增專案。必填：專案名稱、分類；再選類型 a~e、選填 NID。
  4. 新增計畫區間把滑鼠移到專案名稱列，右側會浮出 ＋（新增區間）✎（編輯專案）🗑（刪除專案）。按 ＋ 填區間名稱、開始週、結束週，畫面上就會出現黃色斜紋條。回報是掛在區間上的，沒有區間的專案不會有人需要打卡。
  5. 之後要改起訖週直接點甘特條 → 視窗最上面的「排程與子區間」卡改名稱／週次／NID → 儲存排程。
  6. 調整順序拖曳專案名稱最左邊的 ⠿ 把手即可在同一位成員底下重排（搜尋／篩選中會暫停）。

B. 每週例行

  • 週初概況列看「未回報 n」、⏰ 即將到期
  • 週中催報📊 團隊總結 → 複製待回報名單 → 貼到通訊軟體
  • 逐人檢視看板展開成員，點卡片在甘特圖高亮
  • 評分＋回覆點甘特條評分；看板「主管回覆」留話
  • 出週報看板 ⬇️ 匯出 Excel／📋 複製週報文字
  1. 掌握本週狀況甘特圖上方的「W○○ 全員概況」列：進度條與「已回報 x/y」、四個狀態計數、⏰ 即將到期 n ›（點開有清單，可直接跳到那條區間）。
  2. 催報按 📊 W○○ 團隊總結，右側展開看板。每位成員一列，分段進度條填多少＝交多少，「x/y 回報」還有缺的會轉琥珀色。子工具列的 複製待回報名單（n） 會把「誰缺了哪幾項、項目名稱」組成文字放進剪貼簿，直接貼去催（全員交齊時這顆不會出現）。
  3. 逐人檢視點成員列展開；點任一張任務卡片，左側甘特圖對應的那條區間會亮藍色，邊講邊指很方便；再點一次取消。卡片上的文件圖示可直接開啟成員附的文件。
  4. 評分點甘特條（或從看板定位後點條）開啟視窗，已回報的任務下方有「主管評分微調」五顆按鈕（0.3／0.5／0.8／0.9／1），點下去立即生效。成員回報後預設 1 分，未回報 0 分。
  5. 主管回覆看板成員列右側的 主管回覆，針對「這位成員的這一週」留一段話，全員都看得到（紫色）。已回覆會變成 ✓ 已回覆。
  6. 代成員修正成員填錯或漏填時，header 的 🛠 編輯 W○○ 回報 可代任一成員修任務打卡、非專案、下週預計（會標「✏️ 主管修正」）。要讓成員自己補以前的週，用 ⚙️ 管理 → 🔓 開放歷史補登，用完記得關。
  7. 產出週報看板標題列的 ⬇️ 匯出 Excel（當週全員，兩個工作表）或 📋 複製週報文字；單一成員用其列上的 複製週報。

主管也不能預先回報未來週

系統是「過去到現在」的狀態。切到未來週只能看排程，header 會出現「📅 未來週次・僅檢視」，🛠 與催報入口都會收起。

🏢 高階主管：3 步看到全年度產出

  1. 登入用登入畫面上方的 👑 主管登入（要標記 ★ 重點關注就必須用這個身分；只是要看的話，任何身分都能開成果清單）。
  2. 切到成果清單工具列右側的檢視切換 週檢視｜年度總覽｜成果清單，點 成果清單。畫面變成全年度所有專案的一張平面表：分類、類型、專案名稱、負責人、預計交付具體產出成果、MP Saving、NID。
  3. 篩、排、匯出頂部五張 KPI 卡片點一下就過濾（全部／⭐ 重點關注／💡 具備 MP Saving／🎯 有具體產出／⚠️ 待補充產出效益）；任一欄位標題點一下排序、再點一次換方向；右上角 ⬇️ 匯出 Excel（n 案） 匯出的就是畫面上這 n 案。

想看某位成員的全年排程，切到 年度總覽（整年 53 週縮在一個畫面、不用捲動），再用工具列的成員下拉挑人；想看某一週大家做了什麼，開 📊 團隊總結。

03登入與身分全體

  1. 開啟系統網址由 IT 提供的內網位址（例如 http://主機/Gantt；不同群組有各自的網址，登入頁與標題列會顯示群組名稱）。
  2. 選身分登入畫面上半部是 👑 主管登入，下半部是每位成員的名字；點自己的名字即進入，沒有密碼。身分會記在這台電腦的瀏覽器裡，之後重整或隔天再開都不必重選。
  3. 確認右上角顯示的是你姓名下方會標示「成員／主管」與 Windows 工號。

工號是系統向 Windows 自動取得的（用於稽核紀錄，知道每筆異動是誰在哪台電腦做的）。若你是從非網域環境連線，工號會空白，不影響任何功能。

要換人使用，按右上角的登出圖示；深色／淺色與檢視偏好不會被清除，那屬於這台電腦的使用習慣。

高階主管沒有獨立的登入身分：要標記 ★ 重點關注請用「主管登入」；只是要看成果清單、年度總覽或團隊總結，任何身分都可以。

看到「無權限瀏覽此頁面」

系統可由主管開啟「瀏覽權限卡控」，只有名冊內指定部門／工號的人能進入。若你確定自己應該有權限，請把畫面上顯示的工號告訴主管，由主管在「⚙️ 管理 → 瀏覽權限」加入規則。

06每週要回報的三件事成員主管可代填

按 header 的 📋 本週回報中心（紅色數字＝還沒完成的項目數）。面板頂端有一條完成度進度條與「x / y 項」，下方依優先序分成三區，最後還有一區「已完成打卡任務」：

① 本週待打卡任務

當週有排到的每個計畫區間（或子區間）各一筆。必填，也是紅色數字的主要來源。

② 下週預計執行工作

必填。每人每週一筆，寫下一週打算做什麼。

③ 非專案事項

選填。不屬於任何專案、但值得讓主管知道的事。不計入紅色數字。

三項都完成後，面板底部會變成綠色的 🎉 本週回報已全數完成！返回總表 ›；還沒完成則是「暫存離開（尚有 n 項待完成）」——可以隨時關掉再回來。已交的任務列在面板最下方「🟢 本週已完成打卡任務」，點 修改 › 可以改。

任務打卡

從回報中心點任務，或直接點甘特圖上的條，都會開啟同一個視窗，但版面順序會依你從哪裡開而不同：從回報中心／補登面板開，或成員點自己本週要打卡的條 → 最上面就是本週回報（不用捲動），「前幾週回報」與「排程與子區間」收在下方；從甘特條開（主管、或點的不是本週要打卡的區間）→ 最上面是排程與子區間（已展開），前幾週回報與本週回報在下方（不是本週排定的區間就不顯示本週回報那塊）。標題列會固定在視窗頂端不跟著捲動，往下捲時也看得到這是哪個專案、哪條區間。

  1. 選狀態（三選一）有執行Monitor未執行「有執行」＝本週有實際進度（工作說明必填）；「Monitor」＝例行監控、觀察，沒有實作進度（說明可不填）；「未執行」＝有回報、只是這週沒動，可備註原因。「未執行」與「沒交」是兩回事，該填還是要填。
  2. 填寫工作說明這週實際做了什麼。
  3. （選填）貼上文件連結選了狀態之後欄位才會出現，見下方「文件連結」。
  4. 送出按 儲存進度回報。畫面上方會出現 ✅ 提示，甘特條該週會亮起對應顏色的小點，回報中心的紅色數字少一。

視窗標題旁的 🏆 n 分 是這筆回報的得分：回報後預設 1 分，主管可調整（見評分）。若這條區間有子區間且本週有子區間在進行（子區間打卡開啟時），回報區上方會有一排子區間晶片（✓ 已交／❗未交），點晶片切換要回報哪一個；表單打到一半時不能切，先送出或取消。

兩個省時的捷徑

  • ↩ 沿用上次回報（W○○・狀態）：狀態還沒選時，視窗上方會出現這顆按鈕，一鍵把最近一次的狀態、內容與文件連結帶進來，再改幾個字即可。
  • 前幾週回報：回報區下方的折疊列，點開列出這個區間先前的回報，每一列都有「沿用」，可以挑任一週來套用。

下週預計執行工作（必填）

每人每週一筆，與專案無關。沒填的話，回報中心會顯示紅色的「必填尚未填寫」，主管的團隊看板上也會出現 📅 下週預計未填 標記。

非專案事項（選填）

臨時支援、跨部門協助、教育訓練之類。填了會顯示在主管的團隊看板上。

文件連結（三處都可以貼）

任務打卡、非專案事項、下週預計，三個欄位都能附一個文件連結。主管在看板上點一下圖示就會另開分頁開啟，不必再另外找檔案。

  • 可貼網址（https://…；沒寫 https:// 系統會自動補上），也可貼網路磁碟路徑（\\server\share\檔案.xlsx）或本機路徑。
  • 輸入欄旁邊有一顆試開圖示，存檔前就能先確認貼對了。
  • 清空欄位再送出＝移除連結，不影響已填的文字內容。

路徑類連結可能點不開，這是瀏覽器的限制

Chrome／Edge 預設封鎖從網頁開啟 file://（點了不會有反應也不會報錯），需由 IT 以網域政策放行。優先貼 http／https 連結；若只有路徑，替代作法是從匯出的週報 Excel 開啟——Excel 裡是真正可點的超連結，沒有這個限制。

自己的專案可以切「子區間」

打卡視窗最下方的「排程與子區間」折疊卡裡可以把這段計畫區間再拆成幾個階段（例如 準備資料／跟 IT 溝通／驗證），甘特圖會在專案底下畫成青綠色的縮排子列，讓主管看得到你走到哪個階段。負責人自己就能新增／修改／刪除，不必等主管。怎麼加、有什麼限制、開了「子區間打卡」之後回報怎麼變，都在子區間章。

🎯 具體產出與 MP Saving（負責人要填）

專案名稱列最右邊的 🎯 圖示（已填是實色、未填是淡色）。填「預計交付的具體產出成果」（專案全部做完後會交付什麼：系統上線、SOP 文件…）與「MP Saving」（選填，例如「0.5 人/月」「每年節省 120 小時」）。這是專案層級的欄位，所有計畫區間共用，也是高階主管在成果清單上看的主要內容——負責人與主管都可以填，其他人只能看。成果清單的「⚠️ 待補充產出效益」卡片列的就是還沒填的專案。

補登（修改過去的週次）

平常成員只能回報當週，往前翻是唯讀（header 會顯示「🔒 唯讀檢視中 · 返回本週」）。

當主管開放「歷史補登」時，畫面上方會出現一整條琥珀色警示列，翻到過去週次時 header 也會多一顆 🕘 修改 W○○ 回報；點開是琥珀色標題的補登面板，版面與回報中心相同，可修改那一週的任務打卡、非專案事項與下週預計。所有補登都會留下稽核紀錄。

07子區間：把計畫區間再切成幾個階段負責人主管

有些計畫區間底下實際上還會再分幾個階段，而且可能互相重疊——例如「測試 W10–W27」底下有 準備資料 W10–W15、跟 IT 溝通 W12–W19、驗證 W14–W27。子區間就是把這些階段畫上甘特圖，讓主管一眼看出你走到哪裡。負責人自己就能編，不必等主管。

怎麼新增／修改／刪除

  1. 點甘特條開啟視窗找到「排程與子區間」折疊卡（從甘特條開時它在最上面且已展開；從回報中心開時收在最下方，點標題展開）。
  2. 底部新增列填名稱、開始週、結束週，按 ＋ 新增 或直接按 Enter。起訖週留空＝計畫區間的開始／結束週（欄位裡的灰字就是這個值）；只填名稱直接 Enter，就是一個涵蓋整段計畫區間的子區間。
  3. 每列右側的 ✎／🗑就地修改或刪除。刪除會先確認；刪掉後 10 秒內可按提示上的 ↩ 復原。
  • 起訖週必須落在計畫區間之內；每條計畫區間最多 10 個；子區間之間可以重疊。
  • 每一列是各自即時儲存的，不經過上方排程卡的「儲存排程」。
  • 新增列有打字時，各列的 ✎／🗑 會暫時鎖住（避免把打到一半的內容蓋掉）；送出或清空即恢復。
  • 主管要縮短計畫區間時，若有子區間會跑出新範圍，系統會列出是哪幾個並擋下——先調整子區間再改。

回報怎麼受影響

取決於系統管理者有沒有開「子區間打卡」（伺服器設定檔的總開關，預設關閉、不在網頁上）：

關閉（預設）

子區間只是排程。回報照舊對計畫區間打卡，待回報數、看板、Excel 都不變。

開啟

某一週只要有子區間正在進行，那週就對每個進行中的子區間各自打卡（該週沒有子區間在跑，才對計畫區間本身打卡）。回報中心會逐個子區間列出來、待回報數以子區間計；點子區間的條直接開到那個子區間的回報。

子區間打卡開啟後的細節規則
  • 紅框只框要打卡的那條：有子區間在跑就框子區間、計畫區間本身不框；把子列收合起來時改由計畫區間的條標紅框提醒。
  • 計畫區間的條顯示彙總：全部子區間都交了＝該狀態色點；只交一部分＝琥珀色色點；滑鼠停上去逐條列出誰交了誰沒交。
  • 得分仍以計畫區間計：區間該週分數＝各子區間分數的平均（未回報算 0），主管逐子區間評分。看板「回報 x/y」以子區間計、「得分 x/z」以計畫區間計，兩個分母刻意不同。
  • 切子區間之前已回報過的週維持以計畫區間為單位，不會回頭要求補子區間。
  • 已有回報紀錄的子區間只有主管能刪；刪除可復原。
  • 看板一張卡＝一個子區間（區間名稱旁「› 子區間名稱」藍晶片）、週報 Excel 一列一個子區間（「本週階段」欄）、複製週報文字寫成「區間 › 子區間」。
  • 開關建議在週初、成員尚未回報前切，開了就不要來回切：關閉時已用子區間回報的週會顯示「未回報」（資料保留，再開啟就回來）。

專案本身不會產生回報，回報是掛在「計畫區間」上的。在專案名稱列右側按綠色 ＋ 新增區間，填名稱與起訖週（預設都是目前檢視的週）；區間的 NID 可指定對應到專案的哪一組編號。

同一個視窗的排程卡下方就是「子區間」清單，主管與專案負責人都可以編。要縮短計畫區間時，如果有子區間會跑出新範圍，系統會列出是哪幾個並擋下——先調整子區間再改。完整規則（起訖範圍、上限 10 個、留空＝沿用父區間、子區間打卡總開關、得分怎麼算、誰能刪）見子區間章。

刪除都可以反悔

刪除專案、區間或子區間後，畫面下方的提示會附一顆 ↩ 復原，10 秒內按下即可還原（後端為軟刪除，逾時仍可由資料庫還原）。

拖曳排序

同一位成員底下的專案可拖曳最左側的 ⠿ 把手調整順序（拖專案名稱是選字、不是拖曳）；藍色線標出放開後會落在哪。搜尋或類型篩選啟用時，拖曳排序會暫停——畫面上不是完整清單，拖了會排錯。

🎯 具體產出與 MP 效益

點群組列可收合／展開該成員的專案；列上「本週回報 x/y」是這位成員本週的回報數。沒有專案的新成員也會有群組列，才能為他新增第一個專案。

10⚙️ 管理選單主管

低頻但重要的入口，收在 header 右上角的 ⚙️ 管理 ▾。

🔓 開放／🔒 關閉歷史補登

選單第一項，標籤寫的是「點下去會做的事」、小字是現況。開放中會以琥珀色標示，畫面上方也會出現警示列。詳見「評分與代修」。

👥 成員管理

新增、改名、移除成員。移除是軟刪除；同名成員若曾被移除，再次新增會自動重新啟用原有資料。名下還有專案的成員不能移除，請先用 ✎ 編輯專案改指派負責人。

🔐 瀏覽權限

以人員名冊（工號、DEPTNAME、DEPT_1/2/3）比對決定誰能進入系統。同一條規則內填多欄＝全部符合才通過（且）、規則之間任一符合即放行（或）；只填工號＝該人的白名單。總開關預設關閉；開啟前系統會先用你自己的工號測一次，不通過就不讓開（避免把自己鎖在門外）。面板底部可輸入任一工號測試規則。開啟後採 fail-closed（比對不到就擋），改規則對「下一次進站」生效。

📈 使用統計

近 7／30／90 天的登入次數、每日趨勢、各使用者登入次數與最後登入時間（重新整理自動還原登入也計一次）。

📜 異動紀錄

全系統的稽核紀錄，已翻譯成白話（例如「開啟歷史補登…」而不是 true），含操作人與 Windows 工號。可依日期區間（有「近 7 天／近 30 天」快捷鈕）、操作人、動作、對象類型篩選，也能在結果中再用關鍵字尋找。

子區間打卡不在這個選單裡

「子區間打卡」是伺服器設定檔的開關（appsettings.json → Features:SubIntervalCheckin，預設關閉），刻意不做在網頁上以免誤操作。要開啟請聯絡系統管理者；改檔後使用者重新整理即套用。建議週初開啟、不要來回切換（見「子區間」）。

異動紀錄一次只顯示最近 300 筆

畫面會標示「符合 N 筆、僅顯示最近 300 筆」。要查「上個月某人改了什麼」，請直接用日期與操作人條件縮小範圍，不要用捲動的方式翻找。

多群組部署（系統管理者）

同一套程式可以同時服務多個群組，每個群組有自己的網址、自己的資料庫、自己的成員與專案，彼此完全獨立：MSD 用 /Gantt/、IMD 用 /Gantt_IMD/、EMS1 用 /Gantt_EMS1/、EMS2 用 /Gantt_EMS2/。程式會依「自己被放在哪個 IIS 應用程式路徑」自動挑到對應的資料庫與群組名稱（登入頁、標題列、分頁標題、本手冊的標題都會顯示該群組），四個資料夾放完全相同的程式與設定檔即可。

  • 設定放哪：專案根目錄的 appsettings.Production.json（含正式主機帳密，不進版控；新 clone 請從 appsettings.Production.example.json 複製一份填好）。IIS 環境預設就是 Production，所以每次發佈會自動帶上這個檔，四個應用程式資料夾丟同一份發佈輸出即可，伺服器上不必再手動改任何設定或改群組字樣。
  • 新增一個群組：在 IIS 新增應用程式（例如 /Gantt_XXX）、建立同結構的資料庫（跑 old.sql → new.sql → 10~21 遷移檔），然後在 appsettings.Production.json 的 Sites 加一筆 "Gantt_XXX": { "GroupName": "XXX", "ConnectionString": "…" }，重新發佈（或直接改伺服器上那個檔，存檔即生效、不必回收應用程式集區）。
  • 資料庫搬到別台主機：只改那一筆的 Data Source。
  • DB 結構更新：新的遷移檔要在每個群組的資料庫各跑一次（腳本可重複執行）。某個群組的「使用統計」或某功能載入失敗、其他群組正常，多半就是那個庫少跑了遷移。
  • 目前「子區間打卡開關」「Windows 網域前綴」「名冊來源」等設定是四個群組共用同一個值；哪天某群組要不一樣再拆。

13疑難排解全體

找不到「本週回報中心」按鈕

四種情況會隱藏它：你在成果清單、團隊總結看板開著、年度下拉切到非本年度、或你的身分是主管（主管用的是「🛠 編輯 W○○ 回報」）。切回週檢視、關閉看板、切回今年即可。

翻到過去的週次卻不能填

正常。成員只能回報當週，需由主管開放「歷史補登」。header 會顯示「🔒 唯讀檢視中 · 返回本週」。

我的專案／別人的專案不見了

先看工具列的成員下拉——成員登入預設只看自己；再看搜尋框與 a~e 晶片有沒有殘留條件（篩到 0 筆時畫面會列出生效中的條件）。從看板點過卡片後，成員下拉也會被聚焦到那個人，關閉看板即還原。

甘特圖表頭捲不見／畫面只剩幾欄

表頭是固定的，若跟著捲走請按 Ctrl＋F5 強制重新整理（通常是瀏覽器快取到舊版檔案）。畫面欄位變少多半是團隊總結看板開著，關掉即恢復。

看板開著時右上角的管理／登出按不到

看板是整條從頂端蓋下來的側欄，會蓋住 header 右側。先按 Esc 或看板的 ✕ 關閉再操作。

點了文件連結沒有反應

若貼的是 \\server\… 或 C:\… 這類路徑，瀏覽器預設封鎖從網頁開啟本機／網路磁碟位置。改貼 http／https 連結，或從匯出的週報 Excel 開啟。滑鼠停在圖示上可看到原始路徑，也能自行複製。

子區間切了、但回報還是對整條計畫區間

正常。「子區間打卡」是伺服器設定檔的總開關，預設關閉；關閉時子區間只是排程。要改為逐子區間打卡請聯絡系統管理者。

匯出的 Excel 內容和畫面不一樣

成果清單匯出的是畫面當下顯示的那幾案（含篩選與排序）。若想匯出全部，先點「全部專案」卡片並清掉工具列的篩選再匯出。

畫面停在載入中轉圈

權限檢查有 15 秒逾時，逾時會顯示錯誤畫面與「重試」。若反覆出現，請聯絡 IT。

色彩或版面看起來不對（白底白字之類）

按 Ctrl＋F5 強制重新整理。系統改版後若瀏覽器留著舊的樣式檔就會這樣。
