MSD 專案追蹤總表

使用者手冊

每週在甘特圖上回報進度、由主管評分與講評、再由高階主管檢視全年度產出。這份手冊按角色拆開：先看「你這週要做什麼」，需要細節時再往下翻。

適用版本 2026-08-26（含三處回報的文件連結） 年度 2026（53 週） 使用對象 團隊成員、管理部主管、高階主管
我的身分

01系統在做什麼全體

一張橫跨整年的甘特圖，列出每位成員的專案與「計畫區間」（排定的起訖週）。每到一週，成員針對當週有排到的每個區間打卡回報；主管據此評分、回覆與講評；高階主管則透過成果清單檢視全年度的具體產出與 MP Saving。

每週的節奏

成員

回報三件事

當週排到的任務打卡、下週預計執行工作（必填）、非專案事項（選填）。全部集中在 header 的「📋 本週回報中心」。

主管

檢視、評分、講評

用「📊 團隊總結」看板逐人檢視本週回報，給分數、留週報回覆；缺漏的人可一鍵複製名單去催。

高階主管

看產出

切到「成果清單」，用 KPI 卡片篩出重點關注／有具體產出／有 MP Saving 的專案，需要時匯出 Excel。

關於「週次」

系統的週次是 ISO 週（週一為一週起始），由今天的日期自動推算。2026 年共 53 週。header 中央的「系統週數」顯示的就是你目前正在檢視的那一週，不一定等於本週。

02登入與身分全體

  1. 開啟系統網址由 IT 提供的內網位址（通常是 http://主機/Gantt）。
  2. 在登入畫面點選自己的名字沒有密碼；點下去即進入。身分會記在這台電腦的瀏覽器裡，之後重整或隔天再開都不必重選。
  3. 確認右上角顯示的是你姓名下方會標示「成員／主管」與 Windows 工號。

工號是系統向 Windows 自動取得的（用於稽核紀錄，知道每筆異動是誰在哪台電腦做的）。若你是從非網域環境連線，工號會空白，不影響任何功能。

要換人使用，按右上角的登出圖示；深色／淺色與檢視偏好不會被清除，那屬於這台電腦的使用習慣。

看到「無法瀏覽」畫面

系統可由主管開啟「瀏覽權限卡控」，只有名冊內指定部門／工號的人能進入。若你確定自己應該有權限，請把畫面上顯示的工號告訴主管，由主管在「⚙️ 管理 → 瀏覽權限」加入規則。

工具列的成員下拉是三種檢視共用的同一個篩選，切換檢視不會被重設。登入時的預設值：成員＝只看自己、主管＝全部成員。

畫面變窄時控制項會自動收起

開啟團隊總結看板、或在 1366 以下的筆電／投影機使用時，工具列會把「找資料」用的搜尋框與類型晶片收起來，把空間讓給甘特圖。變寬（或關掉看板）就會自動恢復，不是故障。

05每週要回報的三件事成員主管可代填

按 header 的 📋 本週回報中心（紅色數字＝還沒完成的項目數）。面板頂端有一條完成度進度條，下方依優先序分成三區：

① 本週待打卡任務

當週有排到的每個計畫區間各一筆。必填，也是紅點的主要來源。

② 下週預計執行工作

必填。每人每週一筆，寫下一週打算做什麼。

③ 非專案事項

選填。不屬於任何專案、但值得讓主管知道的事。不計入紅點。

三項都完成後，面板會顯示 🎉 完成畫面。

5.1　任務打卡

從回報中心點任務，或直接點甘特圖上的彩色條，都會開啟同一個打卡視窗。

  1. 選狀態（三選一）有執行Monitor未執行「未執行」是有回報、只是這週沒動，與「沒交」是兩回事，該填還是要填。
  2. 填寫工作說明這週實際做了什麼。
  3. （選填）貼上文件連結見下方 5.4。
  4. 送出畫面上方會出現 ✅ 提示，甘特條該週會亮起對應顏色的小點。

兩個省時的捷徑

  • ↩ 沿用上次回報：狀態還沒選時，視窗上方會出現這顆按鈕，一鍵把最近一次的狀態、內容與文件連結帶進來，再改幾個字即可。
  • 前幾週回報：視窗中段列出這個區間先前的回報（預設展開最近 3 週），每一列都有「沿用」，可以挑任一週來套用。

5.2　下週預計執行工作（必填）

每人每週一筆，與專案無關。沒填的話，回報中心會顯示紅色的「必填尚未填寫」，主管的團隊看板上也會出現 📅 下週預計未填 標記。

5.3　非專案事項（選填）

臨時支援、跨部門協助、教育訓練之類。填了會顯示在主管的團隊看板上。

5.4　文件連結（三處都可以貼）

任務打卡、非專案事項、下週預計，三個欄位都能附一個文件連結。主管在看板上點一下圖示就會另開分頁開啟，不必再另外找檔案。

  • 可貼網址（https://…；沒寫 https:// 系統會自動補上），也可貼網路磁碟路徑（\\server\share\檔案.xlsx）或本機路徑。
  • 輸入欄旁邊有一顆試開圖示，存檔前就能先確認貼對了。
  • 清空欄位再送出＝移除連結，不影響已填的文字內容。

路徑類連結可能點不開，這是瀏覽器的限制

Chrome／Edge 預設封鎖從網頁開啟 file://（點了不會有反應也不會報錯），需由 IT 以網域政策放行。優先貼 http／https 連結；若只有路徑，替代作法是從匯出的週報 Excel 開啟——Excel 裡是真正可點的超連結，沒有這個限制。

5.5　補登（修改過去的週次）

平常成員只能回報當週，往前翻是唯讀（header 會顯示「🔒 唯讀檢視中 · 返回本週」）。

當主管開啟補登豁免期時，畫面上方會出現一整條琥珀色警示列，header 也會多一顆 🕘 修改 W○○ 回報；此時翻到任一過去週次都能修改當週的任務打卡、非專案事項與下週預計。所有補登都會留下稽核紀錄。

06專案與計畫區間主管

新增專案

甘特圖左側依成員分組，每個成員群組列的右側有 ＋ 新增專案。表單欄位：

專案名稱
必填。
分類
自由文字，會出現在凍結欄的「分類」格。
類型 a~e
一級專案/KPI、重大貢獻及亮點、日常管理、其他加分項、主管交辦。對應工具列的彩色篩選晶片。
負責人
可在編輯時改人，專案會整列移到新負責人的群組下。
NID
選填的流水編號，一個專案可含多組。

計畫區間

專案本身不會產生回報，回報是掛在「計畫區間」上的。在專案名稱列右側按綠色 ＋ 新增區間，填名稱與起訖週；區間的 NID 可指定對應到專案的哪一組編號。

已建立的區間，點甘特條 → 視窗下半部即可調整起訖週或刪除。

刪除都可以反悔

刪除專案或區間後，畫面下方的提示會附一顆 ↩ 復原，10 秒內按下即可還原（後端為軟刪除）。

拖曳排序

同一位成員底下的專案可用拖曳調整順序。搜尋、類型篩選或「未回報」篩選啟用時，拖曳排序會暫停——畫面上不是完整清單，拖了會排錯。

🎯 具體產出與 MP 效益

專案名稱列右側的 🎯 圖示開啟。填「預計交付的具體產出成果」與「MP Saving」（選填）。這是專案層級的欄位，所有計畫區間共用，也是高階主管在成果清單上看的主要內容。已填會顯示為實色圖示，未填為淡色。

07團隊總結看板主管成員可看

按 header 的 📊 W○○ 團隊總結，右側會展開一整條側邊面板，逐人列出當週回報。成員預設「只看我的週報」，主管預設全隊折疊。

成員列上的資訊

分段進度條
條填滿多少＝回報了多少。已回報的三段是實心（有執行／Monitor／未執行），未回報留空槽不填色。
n/m 回報
已回報數／本週排定任務數。還有人沒交時轉為琥珀色。
🏆 得分
本週得分＝各任務打卡分數加總（回報預設 1 分、主管可調 0.3~1；未回報 0 分）；滿分＝本週排定任務數。
📅 下週預計未填
折疊狀態下只標「例外」——強制項沒填才會亮這顆。

可以做的動作

  • 點任務卡片：左側甘特圖對應區間會暫時淺藍高亮，方便邊講邊指。再點一次或關閉看板即還原。
  • 複製週報：把該成員本週的完整回報（含文件連結）組成文字複製到剪貼簿，可直接貼到通訊軟體或郵件。
  • 主管回覆：針對「這位成員的這一週」留一段回覆，全員都看得到（紫色區塊）。已回覆時按鈕會轉為紫色的「✓ 已回覆」。留空白送出＝清除回覆。
  • 複製待回報名單（n）：主管專用，且只有真的有人沒交時才出現。內容含每個人缺漏了哪些項目與項目名稱，可直接貼去催。
  • ⬇️ 匯出 Excel：匯出當週全隊週報（含文件連結欄，UNC 路徑會產生真正可點的超連結）。

看板開著時可以繼續操作甘特圖

看板是唯讀側邊面板，主內容區會同步內縮而不是被蓋住，←→ 平移與 H 回本週都還能用。看板開啟時，資料仍會持續自動更新（可以看著成員陸續交上來）。

08評分與代成員修正主管

8.1　打卡評分

開啟任一筆打卡回報，主管會多看到一區「主管評分微調（點擊即時更新分數）」。五個級距：

分數級距
0.3再三交代
0.5說一動做一動
0.8完成老闆交代
0.9超越老闆期許
1.0主動承擔

成員回報後預設即 1 分，未回報為 0 分；只有主管能調整，點下去立即生效。

8.2　🛠 編輯 W○○ 回報（代修面板）

header 上的常駐入口，可代任一成員修正目前檢視中那一週的任務打卡、非專案事項、下週預計，並編輯主管回覆。不需要開啟補登豁免期。

由主管代改的內容，在畫面上會標示 ✏️ 主管修正，成員看得出來是誰動過。

8.3　補登總開關

工具列的 🔒 僅限當週 / 🔓 補登 ON。開啟後全體成員都能回報與調整今年度的所有歷史週次，畫面上方會出現整條琥珀色警示列提醒目前處於豁免期。

這顆是系統級開關

它影響的是所有人的寫入權限，不是只有你自己。用完記得關回「🔒 僅限當週」。

09⚙️ 管理選單主管

低頻但重要的四個入口，收在 header 右上角的「⚙️ 管理 ▾」。

👥 成員管理

新增、改名、移除成員。移除是軟刪除；同名成員若曾被移除，再次新增會自動重新啟用原有資料。名下還有專案的成員不能移除，請先改指派負責人。

🔐 瀏覽權限

以部門名冊比對決定誰能進入系統。規則內的條件是 AND、規則之間是 OR；只填工號＝該人的白名單。總開關預設關閉；開啟後採 fail-closed（比對不到就擋）。

📈 使用統計

依天數區間查看登入次數與使用率。

📜 異動紀錄

全系統的稽核紀錄，已翻譯成白話（例如「開啟歷史補登…」而不是 true）。可依日期區間、操作人、動作、資料類型篩選，也能在結果中再用關鍵字尋找。

異動紀錄一次只顯示最近 300 筆

畫面會標示「符合 N 筆、僅顯示最近 300 筆」。要查「上個月某人改了什麼」，請直接用日期與操作人條件縮小範圍，不要用捲動的方式翻找。

10成果清單高階主管主管

工具列切到成果清單。全年度所有專案的單列平面表：No、分類、類型、專案名稱、負責人、預計交付具體產出成果、MP Saving、NID。唯讀，沒有操作欄——要編輯請切回週檢視用 🎯 入口。

頂部的 KPI 卡片＝可點的篩選器

卡片篩出的專案
⭐ 重點關注項目被標記 ★ 的專案。
💡 具備 MP Saving已填 MP Saving 的專案。
🎯 有具體產出成果已填產出成果的專案。

點卡片即套用篩選（再點一次或用空狀態的清除鈕取消）。所有欄位標題都可點擊排序，點第二次換方向。

★ 重點關注

專案名稱前的星號只在成果清單顯示，點一下即標記／取消。標記存在資料庫，全員共享，不是個人書籤。

匯出 Excel

右上角的 ⬇️ 匯出 Excel（n 案） 匯出的是畫面上當下這 n 案，含套用中的篩選與排序順序——適合帶著離線瀏覽。篩選後 0 案時按鈕會停用（沒有東西可以匯出）。

11通用操作全體

11.1　搜尋與篩選

  • 搜尋框：比對專案與任務名稱。
  • a~e 類型晶片：可多選，右側「清除」一次取消。
  • 成員下拉：三種檢視共用，切換檢視不會重設。
  • 「未回報」晶片（概況列）：點一下只留本週還沒回報的專案，再點取消。主管催報最快的路徑。

若篩到一筆都不剩，畫面會列出目前生效中的每一個條件並各給一顆清除鈕（兩個以上會多給「清除全部條件」），不會只丟一句「找不到資料」。

「未回報」篩到 0 筆是好消息，畫面會顯示 🎉 已全數回報。

11.2　鍵盤快捷鍵

按鍵作用
H / Home回到本週並置中
← →左右平移 4 週
Shift＋← →微移 1 週
Tab → ↑ ↓進入甘特區後上下切換甘特條
Enter開啟目前選取的甘特條；單行輸入欄按下即送出表單
Esc關閉最上層視窗；有未儲存內容時會先確認

header 的系統週數可直接輸入數字再按 Enter 跳週，不必一週一週按。輸入超出範圍會自動夾回邊界。

11.3　深色模式

header 右側的 🌙／☀️ 切換，設定會被記住。深色配色針對投影會議環境調校過，投影時亦可使用。

11.4　自動同步與連線中斷

系統每 60 秒靜默更新一次，別人的異動會自動出現，不需要重整。有彈窗或面板開啟時會暫停更新（避免你正在看的資料在眼前跳動），關閉後恢復。

看到 header 出現「⚠ 連線中斷，畫面為 HH:mm 的快照」

代表連續兩次以上更新失敗，你現在看到的數字是那個時間點的舊資料，不要據此做判斷。按晶片上的「重新連線」；若仍失敗，請聯絡 IT 確認系統或網路狀態。

11.5　同時編輯的注意事項

目前的規則是後存的蓋過先存的。若你和主管可能同時修改同一筆回報，請先關閉彈窗讓畫面更新到最新，再開啟編輯。

12疑難排解全體

找不到「本週回報中心」按鈕

三種情況會隱藏它：你在成果清單、團隊總結看板開著、或你的身分是主管（主管用的是「🛠 編輯 W○○ 回報」）。切回週檢視、關閉看板即可。

翻到過去的週次卻不能填

正常。成員只能回報當週，需由主管開啟「補登」豁免期。header 會顯示「🔒 唯讀檢視中 · 返回本週」。

甘特圖表頭捲不見／畫面只剩幾欄

表頭是固定的，若跟著捲走請按 Ctrl＋F5 強制重新整理（通常是瀏覽器快取到舊版檔案）。畫面欄位變少多半是團隊總結看板開著，關掉即恢復。

點了文件連結沒有反應

若貼的是 \\server\… 或 C:\… 這類路徑，瀏覽器預設封鎖從網頁開啟本機／網路磁碟位置。改貼 http／https 連結，或從匯出的週報 Excel 開啟。滑鼠停在圖示上可看到原始路徑，也能自行複製。

匯出的 Excel 內容和畫面不一樣

成果清單匯出的是畫面當下顯示的那幾案（含篩選與排序）。若想匯出全部，先把 KPI 卡片與所有篩選清掉再匯出。

畫面停在載入中轉圈

權限檢查有 15 秒逾時，逾時會顯示錯誤畫面與「重試」。若反覆出現，請聯絡 IT。

色彩或版面看起來不對（白底白字之類）

按 Ctrl＋F5 強制重新整理。系統改版後若瀏覽器留著舊的樣式檔就會這樣。
